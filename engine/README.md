# Thermal Shield 360 Thermal Engine

The Thermal Engine converts validated environmental observations into thermal indicators used by the Thermal Shield 360 Human Thermal Stress Index (HTSI).

## Planned modules

- Heat Index
- WBGT
- UTCI
- Persistence
- Radiation/Low-Wind Stress
- Forecast Downside
- Human Thermal Stress Index (HTSI)

## Processing flow

Normalized environmental data
→ Quality Control
→ Thermal Indicators
→ HTSI Core
→ Early Warning Layer

## Scientific transparency

Each calculation must document:

- Formula or algorithm
- Input variables
- Units
- Source data
- Assumptions
- Missing-data handling
- Calibration status

Prototype normalization and HTSI weighting must not be presented as medical thresholds or official government warning criteria.
